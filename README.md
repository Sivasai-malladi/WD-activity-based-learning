# 🌐 Web Development – Activity-Based Learning

## 📌 Project Overview
This project focuses on learning web development through practical, activity-based exercises. It helps students understand the fundamentals of website creation by designing and developing interactive, responsive, and user-friendly web pages.

## 🎯 Objectives
- Understand the fundamentals of HTML, CSS, and JavaScript.
- Develop practical web development skills through hands-on activities.
- Design attractive and responsive websites.
- Implement interactive buttons, forms, navigation menus, and layouts.
- Improve creativity, logical thinking, and problem-solving skills.
- Build a portfolio of mini-projects.

## 🛠️ Technologies Used
- **HTML5** – Structures web pages.
- **CSS3** – Adds styling, colours, animations, and responsive layouts.
- **JavaScript** – Adds interactivity and dynamic functionality.
- **Visual Studio Code** – Code editor.
- **Web Browser** – Testing and previewing web pages.

## 📚 Learning Activities

### Activity 1: Personal Portfolio Website
Create a personal website containing your profile, educational qualifications, technical skills, hobbies, projects, achievements, and contact information.

### Activity 2: Library Management Website
Design a library website with book categories, book covers, author details, availability labels, search options, and library rules.

### Activity 3: Travel Booking Website
Develop a travel booking interface with source and destination fields, travel dates, passenger details, fare information, and seat-selection layouts.

### Activity 4: Project Management Dashboard
Create a dashboard displaying project summaries, task cards, team members, priorities, deadlines, progress indicators, and Kanban-style columns.

### Activity 5: Responsive Website Design
Build a responsive web page using CSS Flexbox, CSS Grid, media queries, and interactive navigation elements.

## ⚙️ How to Run the Project
1. Install Visual Studio Code or use another code editor.
2. Create an HTML file named `index.html`.
3. Create `style.css` for styling and `script.js` for interactivity.
4. Link the CSS and JavaScript files to the HTML document.
5. Write your code and save the files.
6. Open `index.html` in a web browser to view the website.
7. Test the website on different screen sizes.

## 💡 Skills Gained
- HTML page structure and semantic elements.
- CSS styling, Flexbox, and Grid layouts.
- JavaScript events and DOM manipulation.
- Form design and validation.
- Responsive web design.
- Debugging and testing.
- Creative thinking and project development.

## 🚀 Expected Outcomes
By completing these activities, students will gain practical knowledge of web development and learn how to transform ideas into functional websites. The activities provide a foundation for building more advanced web applications and developing a professional portfolio.

## 👨‍🎓 Target Audience
B.Tech students, beginners, and learners interested in front-end web development.

## 📄 Conclusion
Activity-based learning makes web development more engaging and practical. Through these projects, students can apply theoretical concepts, develop technical skills, and gain confidence in designing and building websites.
